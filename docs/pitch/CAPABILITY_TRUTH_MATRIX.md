# AEGIS-COP — Capability Truth Matrix

Prepared 2026-10-10 from the code at `main` @ `83fc46c` plus the uncommitted frontend
redesign and fixes (event-driven route re-check, self-declared decision maker and
reason, persisted replacement attempts, labelled demo incidents), and from browser runs
on fresh temporary databases on the same day. **The code
and observed behaviour are the source of truth.** Where this file and older docs disagree,
this file wins.

## Classification

| Label | Meaning |
|---|---|
| **IMPLEMENTED AND VERIFIED** | Code exists *and* an automated test or a recorded browser run exercised it |
| **IMPLEMENTED BUT NOT FULLY VERIFIED** | Code exists; evidence is partial (no automated test, or not exercised in today's runs) |
| **SIMULATED / CONTROLLED DEMONSTRATION** | Works, but its *inputs* are fixed demo values, not real observations |
| **PLANNED / NOT IMPLEMENTED** | No working code |
| **UNAVAILABLE OR NOT CONFIGURED** | Code path exists but has no data source in this deployment |

"Verified" means *the software does what its tests assert*. Nothing in AEGIS-COP has
been validated against real-world outcomes.

## What is algorithmic, seeded, simulated or external

| Kind | Items |
|---|---|
| **Algorithmic (computed by the backend)** | Threat-aware shortest path on the OSM road graph; route–zone intersection; route status (ACTIVE / AT_RISK / INVALIDATED / REPLACED); alternative-route search and the explicit no-safe-route result; threat-zones-crossed count; distance / travel-time deltas; heuristic hazard score (with partial-data upper bound); single-source threat-confidence rule; field-unit state-machine validation; response-plan resource matching (distance-based score) |
| **Seeded (fixed demo fixtures)** | `scripts/demo/seed_demo.py`: 3 active + 1 closed DEMO threats, 4 field units and 2 positions, 3 SIMULATED evidence records + 1 archived; the demo resource list used by response plans |
| **Simulated (fixed profiles triggered by the operator)** | Sensor and field-team reports (`ROAD_FLOODING_SENSOR`, `FIELD_TEAM_BLOCKAGE`), placed at the mission route's midpoint with declared confidence 0.8 / 0.7 and fixed radius 75 m / 40 m; dispatch of resources; the controlled rain scenario; the dead-end washout in `no_safe_route_case.py` |
| **External (only if internet is available)** | Open-Meteo weather (backend), OpenStreetMap and NASA GIBS tiles (browser), Nominatim place search (browser). The IMD regional feed is not configured |
